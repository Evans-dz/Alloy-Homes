# Membership logos

Drop the three association logos here with these exact filenames:

- `suhba.png`   — Southern Utah Home Builders Association (suhba.com)
- `hbautah.png` — Utah Home Builders Association (hbautah.com)
- `nahb.png`    — National Association of Home Builders (nahb.org)

They render on white tiles in the footer's "Member of" strip, so either a
transparent PNG or the standard white-background logo works. Roughly
400-600px wide is plenty; the tile is 112x64 and scales the art to fit.

Until a file is added, that badge shows the short name (SUHBA / Utah HBA /
NAHB) instead of a broken image — nothing looks broken either way.
